# Screenshots to add before publishing

Save screenshots in this directory using these exact names:

- `dashboard.jpg` — the main dashboard (already added);
- `processes.png` — the interactive process list;
- `language-selection.png` — the first-run language selector and logo;
- `terminate-confirmation.png` — the safe process termination dialog.

Use a neutral terminal theme, hide private hostnames/usernames if desired, and
avoid showing tokens, email addresses or unrelated private applications. PNG or
high-quality JPEG is suitable.
