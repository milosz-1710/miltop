## What's new

- Press `R` to open a responsive live view of every logical CPU.
- Each CPU tile shows its current load and a short activity graph.
- The view automatically paginates on computers with many logical CPUs.
- The processor screen now shows the full CPU model, physical-core/thread
  topology, current frequency and maximum frequency.
- The memory screen can show DDR generation, speed, module layout,
  manufacturer and module part number without requiring administrator access.
- Hardware detection runs in the background, preserving fast startup.
- Polish and English interface text was updated for all new features.

## Co nowego

- Klawisz `R` otwiera responsywny podgląd wszystkich logicznych CPU.
- Każdy kafelek pokazuje aktualne obciążenie i krótki wykres aktywności.
- Przy dużej liczbie CPU widok automatycznie dzieli się na strony.
- Ekran procesora pokazuje teraz pełny model, liczbę fizycznych rdzeni i
  wątków oraz aktualną i maksymalną częstotliwość.
- Ekran pamięci może pokazać generację DDR, szybkość, układ modułów,
  producenta i numer modelu bez wymagania uprawnień administratora.
- Rozpoznawanie sprzętu działa w tle i nie spowalnia uruchamiania programu.

## Installation / Instalacja

Debian, Ubuntu and Linux Mint:

```bash
sudo apt install ./miltop_1.2.0_all.deb
```

Fedora:

```bash
sudo dnf install ./miltop-1.2.0-1.noarch.rpm
```
