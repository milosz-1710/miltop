# miltop 1.4.0

This release expands hardware monitoring and makes the process manager much
faster to navigate.

## What's new

- **Working Intel GPU load on more laptops.** When the driver does not expose
  `gpu_busy_percent`, miltop now calculates utilization from unprivileged DRM
  engine counters.
- **Richer GPU details:** temperature when exposed by the driver, current and
  maximum clock, graphics memory, kernel driver, PCI address and measurement
  source.
- **NVIDIA details** through `nvidia-smi`, including load, temperature, VRAM and
  clocks.
- **New Battery tile and view:** manufacturer, model, technology, charge,
  health, cycle count, stored/design energy, power draw and estimated time.
  Desktop systems show a clear no-battery message.
- **Process search:** open Processes and press `/`, then type a name or PID.
- **Configurable process columns:** press `V` to show or hide CPU, RAM, GPU and
  estimated energy-impact columns. The choice is saved.
- **Clickable sorting:** click any visible metric header or Process. The `S`
  key cycles through the enabled columns and name sorting.
- **Clickable process rows** and a scrolling component sidebar for short
  terminal windows.
- **Kept lightweight:** GPU sampling now opens only real DRM descriptors rather
  than every process descriptor, and slower hardware reads are cached without
  reducing visible functionality.

## Po polsku

- działający pomiar użycia zintegrowanej grafiki Intel przez liczniki DRM,
  również gdy sterownik nie udostępnia `gpu_busy_percent`;
- temperatura, taktowanie, pamięć, sterownik i źródło pomiaru GPU;
- pełniejsze dane kart NVIDIA przez `nvidia-smi`;
- nowa zakładka baterii z modelem, kondycją, cyklami, energią, poborem mocy i
  przewidywanym pozostałym czasem;
- wyszukiwanie procesów klawiszem `/`;
- ustawienia widoczności kolumn CPU, RAM, GPU i szacowanego wpływu
  energetycznego pod klawiszem `V`;
- sortowanie procesów po nazwie lub dowolnej widocznej kolumnie klawiszem `S`
  albo kliknięciem nagłówka tabeli.

## Install / instalacja

Debian, Ubuntu, Linux Mint:

```bash
sudo apt install ./miltop_1.4.0_all.deb
```

Fedora:

```bash
sudo dnf install ./miltop-1.4.0-1.noarch.rpm
```
